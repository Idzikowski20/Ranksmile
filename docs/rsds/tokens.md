# RSDS Tokens (canonical)

Prefix: `--rs-*`. Defined in `wordpress-plugin/assets/design/tokens/design-tokens.css`.

## Color / surface

| Token | Role |
|-------|------|
| `--rs-brand` | Brand accent `#F84416` |
| `--rs-brand-hover` | Darker brand |
| `--rs-bg-primary` | Cards / surfaces |
| `--rs-bg-secondary` | Page muted |
| `--rs-bg-tertiary` | Nested |
| `--rs-text-primary` | Headings / body |
| `--rs-text-secondary` | Muted |
| `--rs-text-tertiary` | Meta |
| `--rs-text-on-brand` | On brand buttons |
| `--rs-border` | Default border |
| `--rs-border-strong` | Emphasized border |
| `--rs-status-success` / `-warning` / `-danger` / `-info` | Status colors |
| `--rs-status-*-bg` | Soft status backgrounds |

## Typography

- `--rs-font-body`, `--rs-font-heading` (DM Sans self-host)
- Scale: `--rs-text-xs` … `--rs-text-xl` (+ `--rs-leading-*`)

## Spacing

`--rs-space-1` … `--rs-space-8`

## Radius / border

`--rs-radius-sm`, `--rs-radius-btn`, `--rs-radius-card`  
`--rs-border-width`, `--rs-border-style`

## Motion

`--rs-transition-fast`, `--rs-transition-normal`  
Respect `prefers-reduced-motion`.

## Elevation / z-index

`--rs-shadow-card`, `--rs-shadow-focus`  
`--rs-z-dropdown`, `--rs-z-modal`, `--rs-z-tooltip`
