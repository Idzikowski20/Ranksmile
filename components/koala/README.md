# components/koala — design system

Canonical UI for Ranksmile (Koala UI v11 visuals, Ranksmile naming).

- `tokens/` — colors, typography, effects, semantic Light, Emotion theme
- `primitives/` — flat Button, Input, Checkbox, Tabs, Modal, Badge, Avatar, Select
- `layout/` — KoalaPage, Panel, Settings rows, Table
- `product/` — Card, ActivityFeed
- `core/` — migrated widgets (DataTable, Switch, DateRangePicker, …)
- `icons/` — Icon_Bold via Phosphor Bold

See [REGISTRY.md](./REGISTRY.md). Do not reintroduce Sentry 3D chonk or `#F29964`.
